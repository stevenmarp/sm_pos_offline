POS Offline Mode

Enable full offline functionality for Odoo POS. Work without internet connection - reload, refresh, and continue selling even when offline. All data is cached automatically using modern Service Worker technology.
Key Features

Automatic Caching

All assets, images, and API calls are cached automatically as you use the POS.

Smart Strategies

Uses Cache First for static assets, Network First for API calls, and Stale-While-Revalidate for optimal performance.

Zero Configuration

Works out of the box. No setup required. Just install and it's ready.

How To Use

No configuration needed! The module works automatically once installed.

  • Install the module
  • Open POS online at least once
  • Navigate through products and make a sale
  • Now you can work offline - reload, refresh, everything works!
How It Works

Cache, Go Offline, Reload

Three steps, no technical knowledge required.

1. Cache Everything

As you use the POS, all assets, images, and data are cached automatically.

2. Go Offline

Disconnect from internet or lose connection - the POS keeps working.

3. Reload Anytime

Refresh the page, close and reopen - everything loads from cache instantly.

Important Notes

  • You must open the POS online at least once to cache the data
  • Only visited pages and products will be available offline
  • Requires HTTPS (or localhost) - a browser requirement for Service Workers
  • Orders made offline are kept by the POS and synced when back online
